# 0003 - Styling Strategy using Tailwind CSS v4

- **Date:** 2026-09-01
- **Status:** Accepted

## Context

We need to build mobile-first responsive interfaces efficiently without maintaining bloated custom CSS files.

## Decision

Adopt **Tailwind CSS v4** integrated via the official Vite plugin (`@tailwindcss/vite`).

## Motivation

- The utility-first approach speeds up UI development.
- Native mobile-first design system via responsive breakpoints (`sm:`, `md:`).
- Streamlined setup in Tailwind v4 without verbose configuration files.
